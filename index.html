BUSFORGE

Open commissioning tool for KNX

Import your ETS project, watch the bus and program real KNX devices from a web UI. Self-hosted in one Docker container, no Windows needed.

Public alpha · for technically capable KNX users

Install guide Source on GitHub

What it does

Import
ETS 5/6 projects (.knxproj, password-protected ones too) and manufacturer product databases (.knxprod), or start with an empty project.
Watch
A live bus monitor with decoded values and group-address names, KNX Data Secure telegrams included.
Configure
The device's own parameter pages: conditions, channels, modules, translations.
Program
Parameters, group addresses and full downloads, each backed up first and read back afterwards.
Commission
Assign an individual address and bring up a factory-fresh device.
Keep
Restore points, drift detection between project and device, encrypted export.

Refuse, never pretend

Programming writes bytes into a device in a real building. Busforge refuses what it cannot do with a coded error rather than guessing, and a claim about a device names what was shown on that device: our bytes on it, the same bytes as ETS writes, the device acting on them, and surviving a restart. Passing tests are not counted as proof.

Which products have been tested, operation by operation, is in the compatibility list. A product nobody has tested can still be programmed where its memory model is supported, after you confirm that it is untested.

Quick start

openssl rand -hex 32 > busforge-master.key   # keep this file with your backups
docker run -d --name busforge --stop-timeout 1800 \
  -p 127.0.0.1:3000:3000 \
  -v busforge-data:/app/apps/server/data \
  -e BUSFORGE_MASTER_KEY="$(cat busforge-master.key)" \
  ghcr.io/busforge/busforge:latest

Then open http://127.0.0.1:3000, create an empty project or import your ETS project, and add your KNXnet/IP interface. The master key seals the Data Secure keys Busforge stores; without it a restored backup cannot open them. The published image is for x86_64 hosts; on arm64, build it from the source. The install guide covers the compose setup, product definitions, USB interfaces, the platforms Busforge has run on, and update, backup and restore.

Busforge has no login. Keep it on a trusted network; never expose it to the internet.

KNX Secure

Data Secure: supported

Read and program Data Secure devices, activate a factory device from its certificate, send and decode secured group telegrams. Shown on two products so far.

IP Secure: not supported

Busforge connects to an interface over a plain KNXnet/IP tunnel. An interface that accepts only secure tunnelling cannot be used.

Limits of the alpha

No firmware download, no System 2 or System 300 devices, writes to System 1 devices only in one case, and powerline, RF and IP media never tested on the wire. All hardware work so far was on twisted pair. The full list, with the known issues and their workarounds, is on the limitations page.

Report a problem

Found a fault, or a device that works for you? Open an issue on GitHub. Please do not attach project files, keys or diagnostic packages to a public issue.
