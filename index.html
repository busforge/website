Commission KNX from a browser.

Busforge imports your ETS project, shows the bus live and programs real KNX devices, then reads each device back to check it holds what was written. Self-hosted in one Docker container, on Linux or a Mac.

Install guide Source on GitHub

Public alpha, for technically capable KNX users. Keep your ETS project as a backup.

Quick start

One container, one data volume, one master key that seals the Data Secure keys Busforge stores. Keep the key with your backups: without it a restored backup cannot open them.

Then open http://127.0.0.1:3000, create an empty project or import yours, and add your KNXnet/IP interface. The install guide covers compose, product definitions, USB interfaces, update, backup and restore, and the platforms Busforge has run on.

Busforge has no login. Keep it on a trusted network and never expose it to the internet. The published image is for x86_64; on arm64, build it from the source.

# once; keep this file safe
[ -f busforge-master.key ] ||
  openssl rand -hex 32 > busforge-master.key

docker run -d --name busforge \
  --stop-timeout 1800 \
  -p 127.0.0.1:3000:3000 \
  -v busforge-data:/app/apps/server/data \
  -e BUSFORGE_MASTER_KEY="$(cat busforge-master.key)" \
  ghcr.io/busforge/busforge:latest

From your project to a verified device

Bring an ETS project, or start empty and place devices from the product catalogue, and configure them in the browser. When you program, Busforge builds the device's memory image, checks the device, writes through your interface and reads it back byte for byte. A device that differs is reported, never shown as done.

What a read-back proves
That the device holds Busforge's bytes. Whether they are the bytes ETS would write is a separate check, made against ETS captures product by product and shown in the compatibility list.
Drift before you write
Read any device and see, parameter by parameter, where it differs from your project.
Small writes
A flash writes only the regions that differ, and backs them up first.

The application

Screens from the demo project: an invented house with seventeen devices of ten manufacturers.

Your building, room by room

Every device with its individual address, its product and its programming state, under the floor and room it sits in. Start with an empty project or import the one from ETS.

Group addresses, with their types

Main and middle groups, names and datapoint types, editable in place. Link an address from a device's parameter page, and the bus monitor shows its values decoded.

A preview before every write

The program dialog first checks against the real device and says what it would write. Here a device that Busforge has never programmed: the partial flash is refused, and the full download shows its size before you start it.

What has been shown for this product

Each operation with its state from the kept evidence, here a presence detector tested on everything Busforge supports for it. A product nobody has tested says so, and is written only after you confirm it for the project.

A diagnostic package for the rest

For a device Busforge cannot program yet, it reads identity, properties and planned memory, writes nothing, and lets you review the file before it leaves your computer.

What it does

An open alternative to ETS for your own installation, without Windows. Programming writes bytes into a device in a real building, so Busforge refuses what it cannot do with a coded error rather than guessing.

Import
ETS 5 and 6 projects, password-protected ones too, and manufacturer product databases.
Watch
A live bus monitor with decoded values and group-address names, Data Secure telegrams included.
Configure
The device's own parameter pages: conditions, channels, modules, translations.
Program
Parameters, group addresses and full downloads, over KNXnet/IP or USB.
Commission
Assign an individual address and bring up a factory-fresh device.
Keep
Restore points, drift detection and an encrypted project export.

KNX Secure

KNX Secure is two separate mechanisms. Busforge implements one of them.

supported

Data Secure

Read and program Data Secure devices, activate a factory device from its certificate, send and decode secured group telegrams. Shown on three products so far, plus the download of one secure IP interface.

not supported

IP Secure

Busforge connects to an interface over a plain KNXnet/IP tunnel. An interface that accepts only secure tunnelling cannot be used.

Limits of the alpha

No firmware download, no System 2 or System 300 devices, writes to System 1 devices in one case only, and powerline, RF and IP media never tried on the wire. All hardware work so far was on twisted pair. The full list and the known issues are on the limitations page.

Report a problem

Found a fault, or a device that works for you? Open an issue on GitHub, or let the app prefill one from a device's menu. The reporting guide shows what the link carries and what stays out of a public issue.
